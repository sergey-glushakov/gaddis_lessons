# Backend Trainee: Практика по книге Тони Гэддиса (5-е изд)

## Конфигурация окружения
- OS: LMDE 7 (Debian-based)
- Python: 3.12+
- Пакетный менеджер: uv (Astral)

## Структура проекта
- `chapters/` — Чистый консольный код по главам книги (без GUI и графиков)
- `game_practice/` — Скрипты автоматизации для "The Farmer Was Replaced"
